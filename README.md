# 水土保持计算工具箱

**Water Conservation Calculation Toolkit** — 面向水土保持方案编制的在线计算工具集，纯静态页面，打开即用。

## 在线使用

https://lxf125864-bot.github.io/shuibao-tools/

## 功能 Features

| 工具 | 说明 | 依据 |
|---|---|---|
| 土壤侵蚀量计算 | 通用土壤流失方程 RUSLE：`A = R × K × L × S × C × P`，自动判定水力侵蚀强度等级 | SL 190《土壤侵蚀分类分级标准》 |
| 六项防治目标达标判定 | 扰动土地整治率、水土流失总治理度、拦渣率、土壤流失控制比、林草植被恢复率、林草覆盖率 | GB 50434《开发建设项目水土流失防治标准》 |
| 弃渣场占地估算 | 实方与松方换算 + 边坡修正，反算弃渣场所需占地面积 | 工程经验取值 |

## 本地运行 Local Usage

纯静态页面，无需安装任何依赖：

```bash
git clone https://github.com/Lxf125864-bot/shuibao-tools.git
cd shuibao-tools
# 直接用浏览器打开 index.html 即可
```

或用任意静态服务器：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 判定标准 Standards

**六项防治目标（建设类项目一级标准）**

| 指标 | 目标值 |
|---|---|
| 扰动土地整治率 | ≥ 95% |
| 水土流失总治理度 | ≥ 95% |
| 拦渣率 | ≥ 95% |
| 土壤流失控制比 | ≥ 0.8 |
| 林草植被恢复率 | ≥ 97% |
| 林草覆盖率 | ≥ 25% |

**水力侵蚀强度分级（SL 190）**

| 等级 | 土壤流失量 t/(hm²·a) |
|---|---|
| 微度 | < 2 |
| 轻度 | 2 ~ 25 |
| 中度 | 25 ~ 50 |
| 强烈 | 50 ~ 80 |
| 极强烈 | 80 ~ 150 |
| 剧烈 | > 150 |
